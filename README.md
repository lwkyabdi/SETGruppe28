# SETGruppe28

## Østfold Husflidslag

### Om prosjektet
Dette prosjektet utvikles av SET Gruppe 28 i forbindelse med emnet Software Engineering og Testing.
Målet med prosjektet er å utvikle en nettside for Østfold Husflidslag.
Løsningen skal gjøre det enklere for brukere å finne informasjon om kurs og aktiviteter, nyheter og annet innhold, samt gi mulighet for digital påmelding og tilgang til kontaktinformasjon.
Prosjektet vil også inneholde en administrasjonsdel som gjør det mulig å administrere relevant innhold og informasjon på nettsiden.
